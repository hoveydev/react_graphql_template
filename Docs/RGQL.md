# What is RQGL CLI?

React-GraphQL (RGQL) Command Line Interface (CLI) is a unique command line interface that aims to automate the setup process for a React-GraphQL website by streamlining commands and offering intuitive messaging for a quick and easy (hopefully) setup process.

The CLI operates independently of the client and server applications, making it easy to get your website to a production ready state without having to worry about all the useless setup code once completed.

The repository is designed in a way where you can clone multiple copies and have each one a separate and unique project to suit your needs.

The CLI is designed in a user-friendly way - giving you helpful messaging if you get stuck or intuitive suggestions if you make a mistake (although this can always be improved further). If you notice any bugs or have any ideas for future improvements, feel free to open an issue in our github repository and our team (just me as of now 😋) will get to it as soon as possible.

This CLI is made to be used in conjunction with the `react_graphql_template` repo and is rendered useless outside of that.
