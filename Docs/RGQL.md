# What is RQGL CLI?

React-GraphQL (RGQL) Command Line Interface (CLI) is a unique command line interface that aims to automate the setup process for a React-GraphQL website by streamlining commands and offering intuitive messaging for a quick and easy (hopefully) setup process.

The CLI operates independently of the client and server applications, making it easy to get your website to a production ready state without having to worry about all the useless setup code once completed.

The repository is designed in a way where you can clone multiple copies and have each one a separate and unique project to suit your needs.

The CLI is designed in a user-friendly way - giving you helpful messaging if you get stuck or intuitive suggestions if you make a mistake (although this can always be improved further). If you notice any bugs or have any ideas for future improvements, feel free to open an issue in our github repository and our team (just me as of now 😋) will get to it as soon as possible.

This CLI is made to be used in conjunction with the `react_graphql_template` repo and is rendered useless outside of that.

# Why Rust?

I am still fairly new to Rust development but I have thoroughly enjoyed much of what Rust offers developers in terms of control and help. Although there was a slight learning curve when it came to syntax and some language features such as borrowing and lifetimes, I have been fascinated by the kind of control I can have in programs and how responsive the compiler and borrow checker have been to streamline my learning process.

Something I have learned to love about Rust is the fact that it “just works”. There is rarely a time when, although the code compiles, it doesn’t do what I want. Coming from a language like Javascript (which I know is ironic considering most of this repo is in Typescript), it is easy to make mistakes and break your application. Rust, for whatever reason, doesn’t seem to have this problem.

In addition to this, one of the best things about Rust is the documentation. The Rust language is thoroughly documented and rarely do I consult StackOverflow or Reddit (in some desperate cases) to find the answer to a problem I am having. [The Rust Book](https://doc.rust-lang.org/book/) has been incredibly helpful and is organized almost perfectly.

That being said, this was more of a learning opportunity for me. As stated before, I still consider myself a noob to programming in Rust and this CLI has really helped me hone my skills. I have also found myself utilizing a lot of the lessons I learned in Rust in my work in Swift. There have been some stark similarities with that language as well.
